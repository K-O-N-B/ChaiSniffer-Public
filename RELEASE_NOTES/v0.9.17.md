# Release Notes — v0.9.17

**日期：** 2026-09-03  
**扩展版本：** 0.9.17  
**兼容 Host：** **必须** `host-v0.9.17`（下载目录设置 / fMP4 合并修复）

---

## 扩展（Edge 商店 / 侧载）

### 改进
- 设置中的 **下载目录** 可正确保存并生效（Native Host 协议映射修复）
- 下载完成写入配置的本机目录，不再依赖浏览器「另存为」对话框
- 任务元数据与分片缓存改由 Host 侧管理，下载目录更干净

### 说明
- 侧载包：`ChaiSniffer-Extension-v0.9.17.zip`
- **请同步升级 Host 到 v0.9.17**，否则下载相关能力可能异常

---

## Windows Native Host（必升）

发布包：[ChaiSniffer-Host-Windows-x64-v0.9.17.zip](https://github.com/K-O-N-B/ChaiSniffer-Public/releases/tag/host-v0.9.17)

### 修复 / 改进
- **fMP4（EXT-X-MAP + `.m4s`）** 合并修复：避免产出空壳 / 极小 MP4
- 下载结果写入设置中的下载目录；失败时保留已写入文件便于排查
- 任务目录 / 缓存目录迁到 Host 安装目录下（`.tasks` / `.cache`），不再散落在下载文件夹
- 支持 `CONFIGURE_DOWNLOAD_DIR` 等下载相关协议

**本包不含 Host Python 源码**（仅 `host.exe` + 安装脚本 + `ffmpeg` / CA 证书）。

---

## 用户升级步骤

1. 更新扩展至 **0.9.17**（商店或侧载）
2. 下载并解压 **Host v0.9.17**，覆盖旧目录后重新运行 `setup-bridge.cmd`（粘贴当前扩展 ID）
3. 设置页 **检查是否安装成功** → 全部 ✓
4. 在设置中确认 **下载目录**，再试下载
