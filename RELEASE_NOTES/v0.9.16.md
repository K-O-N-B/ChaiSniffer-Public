# Release Notes — v0.9.16

**日期：** 2026-08-31  
**扩展版本：** 0.9.16  
**兼容 Host：** `host-v0.9.14.1` 或更新（扩展 0.9.12–0.9.16 均可）

---

## 扩展（Edge 商店 / 侧载）

### 新增
- 设置 → **显示视频浮动图标**：可在视频画面上显示/隐藏柴嗅图标；关闭后仍可用工具栏 Popup
- 浮动图标开关保存后立即生效，无需刷新页面

### 改进
- 播放器设置：**推荐 mpv**（主要测试环境）；NeoPlayer 标注为开发中
- 设置页补充产品定位说明（嗅探/桥接 vs 播放器能力）
- 三语 i18n 更新（简体 / 繁体 / English）

### 说明
- 侧载包：`ChaiSniffer-Extension-v0.9.16.zip`（维护者本地 `dist-release/`，商店版 ID 与侧载不同）
- Host 已安装且自检正常时，**无需**重装 Host

## 用户升级步骤

1. 更新扩展至 0.9.16（商店或侧载）
2. **商店版用户**：若首次安装 Host，请用设置页 **商店扩展 ID** 运行 `setup-bridge.cmd`
3. 若 Host 自检已全部 ✓，无需重装 Host
