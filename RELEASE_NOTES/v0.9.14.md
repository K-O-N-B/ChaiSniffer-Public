## 扩展（Edge 商店 / 侧载）

### 新增
- 设置页 **「安装与使用须知」**：Host 分装提醒、平台支持、版权与商店 ID 说明
- 设置页标题、Popup 品牌名、右键菜单 **项目主页** 链接至公开仓库
- 所有下载/文档链接改为 **ChaiSniffer-Public** 公开仓库

### 说明
- 扩展与 Host **源代码不公开**；用户文档与安装包见 Public 仓库
- macOS Host 仍推迟，设置页有明确提示

## Windows Native Host（GitHub Release 资产）

与 v0.9.12 Host 功能一致（若未单独改 Host 代码，可在 Release 说明写「兼容扩展 0.9.12–0.9.14」）：

- B 站分轨下载与混流

- 临时目录清理接口
- 内置 ffmpeg
