# 測試環境說明

> **語言：** [简体中文](../zh-CN/TEST_ENV.md) | [繁體中文](TEST_ENV.md) | [English](../en/TEST_ENV.md)

| 項目 | 說明 |
|------|------|
| 擴充功能版本 | **0.9.16**（商店審核中 / 可側載測試） |
| 輔助應用程式 | **host-v0.9.14.1** 或 [Releases 最新](https://github.com/K-O-N-B/ChaiSniffer-Public/releases/latest) |
| 完整功能 | Windows 10/11 + Edge + 輔助應用程式 + 播放器（推薦 mpv） |
| Mac | 僅嗅探較可靠；下載/播放尚未完整支援 |
| 預設下載目錄 | `%USERPROFILE%\Downloads\mpv-bridge` |

安裝與驗證步驟見 [INSTALL_HOST.md](./INSTALL_HOST.md)。
