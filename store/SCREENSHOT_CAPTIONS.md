# 商店截图说明（需你本地截取）

Edge 要求至少 **1 张**截图，建议 **5 张**（1280×800 或 640×400，PNG/JPEG）。  
请在 **Windows + Edge + 已装 Host + mpv 路径** 环境下截取，避免 URL 含隐私信息。

---

## 截图 1 — Popup 资源列表（必拍）

**画面：** 打开含 HLS/视频的页面 → 点击工具栏柴嗅图标 → Popup 显示资源列表  
**Caption 中文：** 发现当前页面中的流媒体地址  
**Caption EN:** Discover streaming URLs on the current tab

---

## 截图 2 — 设置页自检（必拍）

**画面：** 设置页 →「运行完整自检」→ 列表显示 Host / ffmpeg 等为 ✓  
**Caption 中文：** 一键检查辅助应用、ffmpeg 与播放器  
**Caption EN:** Self-check for helper app, ffmpeg, and player

---

## 截图 3 — 视频浮动图标（v0.9.16 新功能）

**画面：** 视频页鼠标悬停 → 显示柴嗅浮动图标（可带 toast「用播放器打开」）  
**Caption 中文：** 视频上可选浮动图标，一键交给播放器（可在设置中关闭）  
**Caption EN:** Optional float icon on videos — open in your player

---

## 截图 4 — 播放器设置

**画面：** 设置页「播放器设置」→ mpv 推荐卡片 + 播放器路径列表  
**Caption 中文：** 推荐 mpv；支持多个播放器配置  
**Caption EN:** mpv recommended; multiple player profiles

---

## 截图 5 — 安装说明 / 扩展 ID

**画面：** 设置页顶部「扩展 ID」+ Host 安装步骤摘要  
**Caption 中文：** 商店安装后需复制扩展 ID 并完成辅助应用桥接  
**Caption EN:** Copy extension ID and link the Windows helper app
